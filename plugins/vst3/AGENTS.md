# Windows VST3 adapter

Read root AGENTS.md and crates/core/AGENTS.md. This is a tiny native control/status surface built with the pinned official Steinberg SDK. No plugin-side business logic, filesystem scanning, hashing, database, peer network or project path discovery.

- `src/plugin.cpp`: SDK factory, transparent audio processing, selected linked-project UUID in the existing versioned component state, UI-thread SDK dirty notification, save/termination signals. Existing linked saved UUIDs bind directly; unlinked UUIDs are placeholders until the user picks a project.
- `src/bridge.cpp`: bounded local Named Pipe worker; only this worker performs IPC or starts the bundled Rust agent. It pins the module until its own cleanup so terminate never waits for pipe I/O.
- `src/view.cpp`: native Windows linked-project picker, Change project, Share current version and Get collaborator's version. Rust supplies at most 64 names and last folder components, action availability and status text; no plugin path discovery or project business logic. Get/Open TrackMesh requests the same Desktop window and project card; never install into an open DAW project.
- Existing PluginEvent names/fields, protocol names, signing bytes, database values and 24-byte component state remain unchanged. Additive defaulted PluginStatus fields carry picker/status/action capabilities; old plugins ignore them and new plugins show an upgrade notice for old agents. State UUID changes must rebind before commands. Editor close is not session end.
- Selection calls the existing SDK IComponentHandler2::setDirty on the UI thread. A host without that optional interface, or rejecting it, cannot change the selection; do not add an automation parameter as a workaround without approval. Existing saved state restoration still works.
- Last-known remote lineage/source availability stay distinct from live equality. Get stays a DAW-closed Desktop handoff and is disabled when no online known source is available or histories are known divergent.
- CMake disables SDK validator execution and installed-folder links. Do not add/run automated tests or benchmarks. Build/static checks and explicit manual native operation only.
- Save settlement and work-based session lifetime are owned by Rust. Drain queued current-generation save/send signals before session ending, with bounded worker retry; host termination never joins IPC. Forced host-process exit can prevent undelivered events. Launch desktop with `--plugin-owner`; keep save observation independent of filesystem completion. Record limits and actual validation in docs/IMPLEMENTATION.md.
